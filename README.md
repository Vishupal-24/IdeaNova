## ⚡ Problem Statement

Engineering students often face "choice paralysis" when deciding on specializations, internships, and skill paths. **CareerLeap AI** solves this by providing a centralized, AI-driven dashboard that turns ambiguity into a structured visual roadmap.

## ✨ Key Features

  * **🤖 AI Specialization Architect**: An interactive assessment that maps your personality and logic style to the ideal engineering branch (CSE, ECE, ME, etc.).
  * **🗺️ Dynamic Career Roadmaps**: Generates a step-by-step visual timeline including specific tech stacks, projects, and internship milestones.
  * **📄 AI Resume Optimizer**: Analyzes your current profile to generate high-impact professional summaries tailored for ATS (Applicant Tracking Systems).
  * **💬 Engineering Mentor GPT**: A dedicated chat interface powered by **Google Gemini** for instant answers to career queries.
  * **🏆 Gamified Growth**: Earn points and badges as you complete roadmap milestones and profile updates.
  * **🌓 Modern UX**: Fully responsive design with high-performance Dark/Light modes via ShadCN UI.

## 🛠 Tech Stack

  * **Framework**: Next.js 15 (App Router)
  * **AI Orchestration**: Firebase Genkit
  * **LLM**: Google Gemini Pro
  * **Styling**: Tailwind CSS + ShadCN UI
  * **Backend/Auth**: Firebase (Authentication & Firestore)
  * **Icons**: Lucide React

## ⚙️ Installation & Setup

### Prerequisites

  * **Node.js**: v18.0.0 or higher
  * **NPM/Bun/Yarn**

### Quick Start

1.  **Clone the repository**

    ```bash
    git clone https://github.com/vishupal-24/careerleap-ai.git
    cd careerleap-ai
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Initialize Environment**
    Create a `.env.local` file in the root directory and add your credentials (see [Configuration](https://www.google.com/search?q=%23-environment-configuration)).

4.  **Launch Development Server**

    ```bash
    npm run dev
    ```

    Open `http://localhost:3000` (or your configured port) to see the app in action\!

## 🔑 Environment Configuration

To power the AI features, you need to provide the following keys in your `.env` file:

```env
# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key_here

# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY="your_key"
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="your_domain"
NEXT_PUBLIC_FIREBASE_PROJECT_ID="your_project_id"
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="your_bucket"
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="your_sender_id"
NEXT_PUBLIC_FIREBASE_APP_ID="your_app_id"
```
